# Screenshots Directory

This directory contains screenshots of the Sweet Shop Management System application.

## Required Screenshots

Please add the following screenshots to this directory:

1. **login.png** - Login page screenshot
2. **dashboard.png** - User dashboard screenshot  
3. **admin.png** - Admin panel screenshot

## How to Add Screenshots

1. Take screenshots of your application:
   - Login page
   - Dashboard (user view)
   - Admin panel

2. Save them with the names:
   - `login.png`
   - `dashboard.png`
   - `admin.png`

3. Place them in this `screenshots/` directory

4. The README.md will automatically display them!

## Screenshot Guidelines

- **Format:** PNG or JPG
- **Size:** Recommended 1200x800 pixels or similar
- **Quality:** High quality, clear text
- **Content:** Show the full interface

**Note:** If you have screenshots, add them to this directory and they will be visible in the README!
